# Large Module Refactor Status

Overall objective:
Reduce maintenance risk in the largest OrbitalDynamics modules and tests through
facade-preserving, responsibility-focused extraction with no public behavior,
artifact-contract, deterministic-output, or schema-export changes.

Current slice:
Operator-review row JSON Schema provider-manifest and resolver extraction.

Status:
Ready to publish.

Selected slice:
Replace the operator-review row dependency/property dispatchers with exact lazy
provider manifests, and consolidate the identical resolver now used by all
three row schema owners into one internal helper.

Why this slice:
The operator-review row has 42 schema and 11 property pairs in the same
facade-private dispatch shape. Two proven row owners now duplicate the same
nine-line lazy resolver; adding a third copy would create avoidable maintenance
risk. One narrow internal resolver keeps lookup behavior uniform while all
provider builders remain private to `Schema`.

Public facade to preserve:
`OrbitalDynamics.Schema.json_schema/1`, `json_schema_bundle/0`, all schema
write functions, exact `cadence_import_manifest.v1` generated bytes, and
executable validation behavior.
