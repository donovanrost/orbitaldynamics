# Orekit 13.1.7 J2-drag LEO truth bundle

This directory is a content-bound external numerical truth case generated by
Apache Orekit 13.1.7. It covers eight propagated Cartesian states and every
AOS/LOS and cylindrical-eclipse ingress/egress boundary in the declared
0--21,600 TDB-second horizon.

The external force path is Orekit `NumericalPropagator` with the Hipparchus
fixed 10 s classical RK4 integrator, automatic Newtonian attraction,
`J2OnlyPerturbation`, `DragForce`, `SimpleExponentialAtmosphere`, and
`IsotropicDrag`. The checked-in Java generator calls those upstream library
implementations; it does not reimplement OrbitalDynamics force equations.

`manifest.json` declares the complete model, frame/time/data identity,
detectors, tolerances, toolchain, dependency checksums, and claim boundary.
`case.properties` is the byte-exact generator input. `source-manifest.sha256`
binds all source/config/lock/command bytes, and `reference-output.json` is the
raw, full-precision Orekit result. `SHA256SUMS` binds the three top-level
identities used by the Elixir verifier.

## Reproduce

Docker is the only host dependency. The script uses the digest-pinned
`maven:3.9.11-eclipse-temurin-21` Linux/arm64 image, downloads checksum-pinned
Orekit/Hipparchus jars into a temporary directory, verifies each jar, compiles
the generator there, and removes that directory on exit. It does not add Java
or Maven runtime dependencies to the Elixir library.

From the repository root:

```sh
bundle=priv/validation/external_truth/orekit_13_1_7_leo_j2_drag_access_eclipse
"$bundle/generate.sh" /tmp/orekit-j2-drag-reference-output.json
shasum -a 256 /tmp/orekit-j2-drag-reference-output.json
cmp "$bundle/reference-output.json" /tmp/orekit-j2-drag-reference-output.json
(cd "$bundle" && shasum -a 256 -c SHA256SUMS)
```

The reproduced result SHA-256 must be
`fe7092587cd9eb8c4e2c51b84462cd795543c7b9ff149ff72c4efc2abe80bb43`.
