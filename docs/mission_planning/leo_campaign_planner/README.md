# LEO Constellation Campaign Planner

The LEO-focused campaign planner spec, split into one file per major
version boundary. This replaces the original
`docs/leo_constellation_campaign_planner.md` monolith.

- [00_product_target.md](00_product_target.md) — what the product is and
  who it serves.
- [01_v1_campaign_plan_generation.md](01_v1_campaign_plan_generation.md) —
  V1 inputs, core capabilities, outputs, and Cadence integration.
- [02_v2_rolling_operations_planner.md](02_v2_rolling_operations_planner.md) —
  rolling-horizon replanning, resource-aware scheduling, plan repair,
  the implemented V2 repair slice, multi-objective optimization, and
  uncertainty-aware planning.
- [03_v3_mission_orchestration_system.md](03_v3_mission_orchestration_system.md) —
  digital-twin planning, strategic campaign optimization, what-if/branch
  planning, policy-aware autonomy, fleet-level resource allocation, learning
  from operations, and multi-regime expansion. The "Implemented V3 Strategy
  Slices" section expands into [`03_v3_implemented_slices/`](03_v3_implemented_slices/).
- [04_implementation_implications.md](04_implementation_implications.md)
- [05_near_term_product_slice.md](05_near_term_product_slice.md)
