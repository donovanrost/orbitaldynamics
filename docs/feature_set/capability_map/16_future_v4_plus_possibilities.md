# 16. Future V4+ Possibilities

- Architecture gate: the
  [accepted V4 activation decision](../v4_activation_gate_decision.md) keeps V4
  implementation and entry points out of the supported release line until a
  Level 5 exit review records an evidence-backed activation decision.
- `implemented`: no V4 platform layer yet; the V3 artifact establishes the
  substrate for future work.
- `partial`: V3 already carries mission state, resource summaries, branches,
  operational feedback, and approval policy, but these are not yet a live
  planning service.
- `near-term`: keep V1 through V3 as the supported public planner surfaces and
  complete the Level 5 exit review before activating V4.
- `later`: persistent digital twin integration, robust multi-future planning,
  simulation branch trees, calibrated operational models, cross-regime support
  for MEO/GEO/cislunar/interplanetary cases, formation flying, deployment
  campaign planning, and approval-bounded autonomy.
- `out of scope`: replacing Cadence as the operator workflow system.
