# Level 1: Reproducible Studies

Feature complete when many scenarios can be loaded from JSON, run locally or
across BEAM nodes, isolated by scenario, ordered deterministically, and archived
with run metadata, seed manifests, assumptions, and compact reports.

Status: `implemented` for the first useful study shape, including guarded
artifact reuse for manifest-driven runs. It remains `partial` for schema
versioning, checkpointed execution, and long-running failure recovery.
